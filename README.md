# 🌍 Sistema de Pronóstico Climático Multinivel

Aplicación web interactiva desarrollada en Python y Streamlit que integra modelos matemáticos de clima global con datos locales de Medellín, Colombia.

## 📚 Fundamento Teórico
El sistema se basa en el libro *Mathematics and Climate* (Kaper & Engler, 2013):
- **Capítulo 16:** Modelo *Delayed-Oscillator* para la predicción de ENSO (El Niño/La Niña).
- **Capítulo 9 y 19:** Análisis de regresión y eventos extremos para vincular la señal global con impactos locales (lluvias y temperatura en el Valle de Aburrá).
